# Alexendros — Auditoría, diseño y desarrollo web

Sitio profesional de [alexendros.dev](https://alexendros.dev): página web, tienda en internet, aplicaciones para Linux, protocolos de gestión e integración de Inteligencia Artificial. Desde Valencia.

| Servicio                                                                                     | Para quién                                                                               |
| -------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------- |
| [Portal de inicio (web/landing)](https://alexendros.dev/servicios/#portal-heading)           | Profesionales y negocios locales que necesitan una web clara lista para captar consultas |
| [Posicionamiento en buscadores](https://alexendros.dev/servicios/informe-comercial/)         | Quienes necesitan un informe SEO técnico y un plan de ajustes con métricas verificables  |

Más detalle y precios orientativos (+ IVA) en [Hoja de Servicios](https://alexendros.dev/servicios/). Cómo trabajo en [Proceso y entrega](https://alexendros.dev/proceso-y-entrega/). Proyectos reales en [Proyectos](https://alexendros.dev/proyectos/).

## Cómo empezamos

1. Cuéntame tu situación en [Contacto](https://alexendros.dev/contacto/) o escribe a [contratacion@alexendros.dev](mailto:contratacion@alexendros.dev).
2. Si prefieres una llamada breve sin coste: [diagnóstico en Cal.com](https://cal.com/alexendros/diagnostico).
3. Acordamos alcance, plazos y entregables antes de empezar.

Trabajo desde Valencia (remoto o presencial según el proyecto). El sitio prioriza claridad, accesibilidad y velocidad; el tracking comercial solo se carga con consentimiento previo y granular.

## Este repositorio

Código fuente **público** del sitio en producción ([`Alexendros/alexendrosdev`](https://github.com/Alexendros/alexendrosdev)). Para contribuir o desplegar, empieza por [CONTRIBUTING](CONTRIBUTING.md). Arquitectura en [ARCHITECTURE.md](ARCHITECTURE.md); estándares, protocolos y registros en [docs/](docs/). Contrato para agentes: [AGENTS.md](AGENTS.md). Avisos de seguridad: [SECURITY.md](SECURITY.md).

```bash
pnpm i
pnpm dev    # http://localhost:4321
```

Node 22 + pnpm 9.15.9 (`packageManager`). Producción en Vercel Hobby (`alexendros-dev`); el merge a `main` publica el sitio.
