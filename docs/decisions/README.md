# Decisiones

La fuente canónica de decisiones de plataforma es [`docs/audits/decisions.json`](../audits/decisions.json), validada con `pnpm check:records`.

Este directorio queda reservado para ADR narrativos cuando una decisión necesite contexto adicional. Un ADR debe enlazar el identificador del registro tipado y nunca duplicar ni contradecir su estado vigente.
